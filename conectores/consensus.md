# Consensus

Busca semântica em mais de 400M de papers revisados por pares, com respostas citando os estudos.

## Quando usar
- "O que a literatura diz sobre X?", com referências numeradas
- Primeira olhada num tema antes de uma revisão maior

## Quando não usar
- Revisão completa com triagem e planilha: LR-AI
- Engenharia muito aplicada (datasheets, normas): a base é de papers

## Componentes
| Ferramenta | Para quê |
|---|---|
| search | busca ranqueada por relevância |
| threads (create, add, find, get) | conversas de pesquisa salvas |

## Combina com
- [Elicit](elicit.md) para aprofundar o que o Consensus achar

## Notas
- Limite de ~3 buscas por vez; erro de rate limit pede espera de 30 s.
