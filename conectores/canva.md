# Canva

Acesso à sua conta do Canva: buscar, criar, preencher templates e exportar designs.

## Quando usar
- Peças rápidas a partir de templates do Canva (posts, flyers, apresentações)
- Preencher um template existente com dados

## Quando não usar
- Interface de software: Figma
- Documento de texto: Docs ou Word

## Componentes
| Ferramentas | Para quê |
|---|---|
| busca, criação, autofill, export | gerenciar designs do Canva |
