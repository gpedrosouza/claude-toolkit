# design

Skills para o trabalho de design de produto: crítica, design system, textos de interface, acessibilidade, pesquisa com usuários e handoff para desenvolvimento.

## Quando usar
- Revisar uma tela ou mockup (hierarquia, usabilidade, consistência)
- Escrever textos de botão, erro e estados vazios
- Auditar acessibilidade (WCAG 2.1 AA) ou preparar a especificação para o dev

## Quando não usar
- Criar o design em si: usar o Figma (plugin) ou um design no próprio Claude

## Componentes
| Skill | Para quê |
|---|---|
| design-critique | feedback estruturado sobre uma tela |
| design-system | auditar e documentar componentes e tokens |
| ux-copy | microcopy, mensagens de erro, CTAs |
| accessibility-review | contraste, teclado, alvos de toque, leitor de tela |
| user-research, research-synthesis | planejar entrevistas e sintetizar resultados |
| design-handoff | spec de layout, tokens, estados e breakpoints |

## Combina com
- [Figma (plugin)](figma.md) para criar o que for criticado aqui

## Notas
- `user-research` é pesquisa com usuários, não pesquisa acadêmica.
